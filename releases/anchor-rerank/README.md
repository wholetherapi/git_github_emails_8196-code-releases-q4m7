# Anchor-Conditioned Re-ranking for Long-Context Retrieval

Reference implementation for the paper *Anchor-Conditioned Re-ranking for Long-Context Retrieval*.

## Release Status

**✅ Released**

The implementation, experiment scripts, and evaluation utilities for this
paper are publicly available in this release directory.

## Contents

- `src/` - model and training code
- `data/` - processed data placeholders
- `experiments/` - experiment configuration
- `notebooks/` - exploratory notebooks
- `results/` - result artifacts
- `tests/` - smoke tests
